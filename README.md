# FHE Accelerator Simulators 02 — Anatomy of CKKS Bootstrapping

ModRaise, CoeffToSlot (a homomorphic DFT evaluated with baby-step giant-step rotations), EvalMod (a polynomial approximation of modular reduction) and SlotToCoeff, with exact operation counts per stage, where the levels go, and the data-movement profile that makes bootstrapping a memory problem.

Topics: ModRaise, CoeffToSlot, EvalMod, SlotToCoeff, BSGS, Levels.
